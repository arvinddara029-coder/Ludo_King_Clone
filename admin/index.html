📋 Session Code kaise nikale? (App se)

  1. Mobile me Ludo King app kholo (package com.ludoking.mindnova).
  2. Home screen par Settings (⚙️ gear icon) dabao.
  3. Settings list me sabse neeche Version wali line par 3.5 second ke andar 5 baar tap karo.
  4. Ek secret box khulega — usme 6-letter SESSION CODE dikhega. Code copy dabao.
  5. Is panel me Session Login tab kholo, code paste karo, Connect Session dabao. Bas!

How to get session code (English): Open app → Settings → tap the Version row 5 times within 3.5 seconds → copy the 6-letter code → paste it in Session Login here.

👑 Developer setup (sirf ek baar)

  1. FIREBASE_SETUP.md padhkar Firebase project banao, Authentication me apna 1 email+password user banao, Realtime Database banao.
  2. google-services.json file app/ folder me rakho aur app rebuild karo.
  3. Is file (admin/index.html) me sabse neeche <script> me FIREBASE_CONFIG + DEVELOPER_UID bharo (Firebase Console → Project Settings + Authentication → user UID).
  4. Yahan Developer Login karo — saare live sessions ki list dikhegi, kisi par bhi Control dabao.
